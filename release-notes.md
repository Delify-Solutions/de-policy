# 2.0.1

## Tiếng Việt

- Sửa chế độ Red Team trong phần chọn chế độ.
- Sửa lỗi chế độ tùy chỉnh trong phần cài đặt quyền.
- Bổ sung khả năng xem các cửa sổ đang chạy.

## English

- Fixed Red Team mode in the mode selector.
- Fixed custom mode in permission settings.
- Added support for viewing running windows.

## Cài đặt và cập nhật

Cài đặt bằng thư mục cục bộ sau khi giải nén; bản web và bản desktop cài riêng, áp dụng riêng. Hiện tại đây là bản cục bộ cố định, tính năng cập nhật trực tuyến và chuyển kênh đã tắt. Các bước chi tiết xem tại [README tiếng Việt](./README.vi.md).
